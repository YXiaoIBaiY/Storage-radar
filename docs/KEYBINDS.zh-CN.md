# 操作与快捷键

> English: [KEYBINDS.md](KEYBINDS.md)

存储雷达的输入分两类：

1. **malilib 热键（键盘）** —— 可以在配置里随便改，保存在模组配置文件中。
2. **界面内操作（鼠标 + 界面里的按键）** —— 固定，属于网格界面本身。

## 可改键的热键

| 热键 | 默认 | 生效场景 | 配置项 | 说明 |
| --- | --- | --- | --- | --- |
| 打开存储雷达 | **B** | 游戏内 | `openStorageGui` / 打开展示界面 | 需要已进入世界且装了 ChestTracker；缺任何一个都会用物品栏上方文字说明原因 |
| 取悬停格 / 取选中 | **R** | 存储雷达界面内 | `takeHoveredItem` / 取物热键 | 语义见下文「R 的规则」 |
| 取消当前取物 | **ESC** | 游戏内，仅在取物进行中 | `cancelTake` / 取物中取消 | 停掉 Baritone 并清空取物队列。取消时这次按键会被吞掉，不会弹暂停菜单；没在取物时 ESC 保持原版行为 |

**改键方法：** 打开模组配置界面 → 点键位输入框 → 按新键。
配置界面入口有三处：

- Mod Menu → Storage Radar → **Config** 按钮；
- 存储雷达界面里的 **配置** 按钮；
- malilib 共用的配置切换列表（masa 系模组统一入口）。

malilib 自己维护按键表，不占用原版 `KeyMapping`，所以不会和 Baritone / Tweakeroo / MiniHUD 抢键。如果某个键已被别的 malilib 模组占用，换一个即可。

## 界面操作

### 鼠标

| 操作 | 输入 | 结果 |
| --- | --- | --- |
| 选中 / 取消选中 | 格子上 **左键** | 切换这一格的选中状态，并把它设为连选起点 |
| 只选这一格 | **Ctrl + 左键** | 清空选择，只选这一格 |
| 连选一段 | **Shift + 左键** | 选中从起点到这一格之间的所有格子（可以跨页） |
| 选中相同物品 | **Alt + 左键** | 把**本页**内所有「同物品 + 同组件」的格子加入选择 |
| 只取这一格 | 格子上 **右键** | 立即对这一个槽位发起取物，不改动已选内容 |
| 上一页 / 下一页 | **鼠标滚轮** | 上滚 = 上一页，下滚 = 下一页（鼠标在界面任何位置都生效） |
| 查看信息 | 鼠标悬停格子 | 显示物品提示框；网格左侧显示容器名、坐标、槽位号、距离 |

### 键盘（界面打开时）

| 操作 | 输入 | 结果 |
| --- | --- | --- |
| 取悬停格 / 取选中 | **R** | 取物热键，语义见下 |
| 取全部选中 | **Tab** | 等同「取选中」按钮 |
| 全选本页 | **Ctrl + A** | 把本页所有格子加入选择 |
| 上一页 / 下一页 | **← / →** | 翻页 |
| 跳到指定页 | 在页码框里输入数字 | “第 x / y 页”左边的输入框，边输入边跳转 |
| 搜索 | 点搜索框后输入 | 支持中文名、英文名、全拼、首字母 |
| 中止取物 | **ESC** | 取消寻路、清空取物队列，然后关闭界面 |
| 关闭界面 | **ESC**（没有取物进行时） | 关闭界面 |

### 按钮

| 按钮 | 作用 |
| --- | --- |
| `< 上一页` | 上一页 |
| `刷新` | 重新读取 ChestTracker 记忆并重建列表 |
| `下一页 >` | 下一页 |
| `取选中` | 对全部选中格发起取物 |
| `清空选择` | 清空选择（刷新后也不再保留） |
| `配置` | 打开模组配置界面 |

窗口太小时会先砍掉第二排按钮；「配置」按钮在 Mod Menu 里始终能进。

## R 的规则

按 `R`（或你改的键）时按以下顺序判断：

1. **选中了多格** → 取全部选中（等同 Tab / 取选中）。
2. **没有多选、鼠标正悬停在某格上** → 只取悬停的那一格。
3. **恰好选中一格、鼠标没悬停** → 取那一格。
4. 什么都没选也没悬停 → 不动作。

## 注意

- 搜索框或页码框聚焦时，输入都进输入框：`R`、`←/→`、`Ctrl+A` 不会当热键处理。
- 鼠标滚轮即使停在搜索框上也是翻页。
- 界面内的鼠标操作、Tab、方向键、滚轮都不能改键。
- 取消热键（默认 **ESC**）只在取物进行中拦截。它注册为「处理时取消原版按键」，所以不会顺手弹出暂停菜单；没在取物时 ESC 完全不受影响。
