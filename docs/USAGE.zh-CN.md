# 使用说明

> English: [USAGE.md](USAGE.md)

存储雷达的完整使用流程。快捷键表见 [KEYBINDS.zh-CN.md](KEYBINDS.zh-CN.md)，全部配置项见 [CONFIG.zh-CN.md](CONFIG.zh-CN.md)。

## 1. 第一次使用前

存储雷达不扫描世界，它读的是 **ChestTracker 的容器记忆**，记忆靠你正常游玩积累：

1. 装好 ChestTracker（1.21.11 版本）和本模组。
2. 正常打开箱子 —— 每个开过的容器都会连同内容被记录下来。
3. 物品挪动过之后，再开一次对应箱子，让记忆和实际一致。

从没开过的容器，雷达里不会出现。

## 2. 打开雷达

- 在世界里按 **B**（默认键）。
- 雷达以全屏界面打开。

如果弹出的是一行提示文字，说明缺条件：需要先进入世界，或者没装 ChestTracker。

## 3. 界面构成

```
                [ 搜索框: 搜索物品名 / Filter ]
 ┌──────────────────────────────────────────────────┐
 │  容器信息           9 × 6 格的物品网格            │   状态 / 取物进度
 └──────────────────────────────────────────────────┘
           [< 上一页] [刷新] [下一页 >]
        [ 页码输入框 ] 第 1 / 3 页
 ┌──────────────────────────────────────────────────┐
 │  你的背包（4 行）                                 │
 └──────────────────────────────────────────────────┘
```

- **一格 = 某个容器的某个槽位 = 一组物品。** 不做合并：同一个箱子里三组钻石就是三格。
- **鼠标悬停**格子会显示物品提示框；开着「显示容器位置」时，网格左侧会画出容器名、坐标、槽位号和距离。
- **左侧提示文字**重复鼠标手势；**右侧**显示物品种数、页码、已选数量和取物实时进度。
- **背包栏**贴在快捷栏上方，方便对照身上已有的东西。

## 4. 找物品

用顶部的搜索框，大小写不敏感，支持：

- 中文名：`钻石`
- 英文名：`diamond`
- 全拼：`zuanshi`
- 首字母：`zs`

只匹配物品名本身，不是正则；一般用子串即可。

不搜索时，列表排序：

- **按数量排序**（默认开）：堆叠数量从大到小，数量相同按距离；
- 关掉后：纯按距离。

找大宗材料可以按数量排；想找最近的一份就把「按数量排序」关掉。

## 5. 选中格子

| 操作 | 效果 |
| --- | --- |
| 左键 | 切换这一格的选中 |
| Ctrl + 左键 | 只选这一格 |
| Shift + 左键 | 从起点连选到这一格（可以跨页） |
| Alt + 左键 | 把本页所有相同物品加入选择 |
| Ctrl + A | 全选本页 |
| 清空选择按钮 | 清空选择 |

只要容器槽位还在，选中的内容在按「刷新」后仍然保留。

## 6. 取物

### 取一格

- 格子上 **右键**：立刻取这一格（不改变已选内容）。
- 或鼠标悬停在格子上按 **R**。

### 取多格

1. 选好要取的格子。
2. 按 **R**（或 **Tab**，或点 **取选中**）。

### 接下来会发生什么

1. 雷达界面关闭（「取完关闭界面」开着时），Baritone 开始走向第一个容器。
2. 到达后右键开箱，**对准确槽位 shift 点击**（普通快速移动，只搬这一组）。
3. 等服务器回包确认到手，然后**不关箱**直接取同一容器里选中的下一格。
4. 该容器选中的格子全取完，关箱，走向下一个容器。
5. 物品栏上方持续播报进度（`[容器 2/3] 前往 …`、`取出 …`、`确认到手…`）。最后一条约停留 4 秒，然后淡出消失。

结果播报会给出**目标数量**（缓存里这一组有多少）和**实际到手数量**。缓存过期时实际可能更少，甚至直接提示这一格已空或被搬走。

### 其它维度的容器

不支持。只列出、只取当前维度。

## 7. 中止与刷新

- **ESC**（取消热键，可改键）在取物进行中随时可用：停掉 Baritone、清空队列，并且这次按键会被吞掉，不会弹暂停菜单。
- 存储雷达界面里按 **ESC**：中止队列并关闭界面。
- **刷新**：重新读取 ChestTracker 记忆。重新开过箱子之后、或看到「缓存过期」提示时用它。
- 取物中途被打断（死亡、切维度、手动关箱子等），按 ESC 或重开雷达再来一次。

## 8. 小窗口 / GUI 尺度太大

布局是自适应的：先减网格行数，再砍第二排按钮，再撤背包栏。实在放不下时只留搜索框，并提示放大窗口或调低 GUI Scale。正常分辨率下都能完整显示。

## 9. 实用建议

- 半径别太大（16–32 就够）。它只是过滤缓存列表，不扫世界，但列表太长不好翻。
- 储物间里的容器改个名，再开「只看命名容器」，可以避开装饰用的箱子。
- 想找最近的一份而不是最多的那一堆，就把「按数量排序」关掉。
- 「寻路允许破坏」默认关；Baritone 老是卡住再考虑打开，取物结束后会自动恢复原值。
- 自动取物在公开服务器上可能违规 —— 用之前确认服务器规则。

## 10. 已知限制

- 只处理**当前维度**。
- 只认 **ChestTracker 记录过**（至少开过一次）的容器。
- 缓存数量是快照，可能过期。
- 超过约 4.5 格的容器需要 **Baritone**。
- 一次取物按格搬运；它不会「一键把这个物品在全世界所有箱子里的都拿来」—— 想取哪些格就选哪些格（Alt + 左键很快）。
